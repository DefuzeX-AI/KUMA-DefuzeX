# Security Policy

## Supported versions

Security fixes are provided for the latest released version of the DefuzeX
Python SDK. Upgrade to the latest release before reporting a problem that may
already have been fixed.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, private service
details, or user data in a public issue.

Use GitHub's private vulnerability reporting for
`DefuzeX-AI/KUMA-DefuzeX` from the repository's **Security** tab.
Include the affected version, a minimal reproduction, expected impact, and any
safe mitigation you have identified. Do not include real API keys or third-party
data.

Maintainers will acknowledge the report through the private advisory and keep
status updates there. Public disclosure should wait until a fix and coordinated
release are available.
